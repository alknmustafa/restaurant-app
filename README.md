## Shoppi Full-Stack Food Delivery Web Application

### Overview

Shoppi is a full-stack food delivery web application where users can discover restaurants, explore cuisines, filter restaurants based on their preferences, and place food orders.

#### 🚧 Project Status: Currently under active development.

## ✨ Features

### 👤 Authentication

- User registration and login
- Password hashing with bcrypt
- JWT-based authentication
- Protected API routes

### 🔎 Restaurant Discovery

- Browse restaurants
- Discover popular restaurants
- Explore different cuisine types
- Search restaurants
- Filtering features

### 🍔 Food & Ordering
- Browse food items
- Select food from restaurants
- Add items to an order
- Place food orders

### 🛠️ Tech Stack
#### Frontend

- React
- JavaScript
- Tailwind CSS

#### Backend
- Node.js
- Express.js
- REST API

#### Database
- MongoDB
